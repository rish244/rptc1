--------------------------------------------------------------------------------
TARIKA 1 — SABSE AASAN: SEEDHA BROWSER MEIN (0 setup, 10 second)
--------------------------------------------------------------------------------
  1. ZIP ko extract karein (Right click -> Extract All).
  2. Folder kholein -> "index.html" par DOUBLE CLICK karein.
  3. Website Chrome mein khul jayegi. Bas!

  Note: Is tarike mein bhi sab kuch kaam karta hai (booking, admin, history)
  kyunki website browser ke andar hi chalti hai.


--------------------------------------------------------------------------------
TARIKA 2 — VS CODE (recommended, sabse acha experience)
--------------------------------------------------------------------------------
  STEP 1: VS Code install karein (agar nahi hai):
          https://code.visualstudio.com/

  STEP 2: VS Code kholein -> File -> Open Folder...
          -> "RPTC-Website" folder select karein -> Select Folder

  STEP 3: Left side "Extensions" icon (ya Ctrl+Shift+X) -> search karein:
          "Live Server"  (Ritwick Dey wala)  -> Install

  STEP 4: Left panel mein "index.html" par right click ->
          "Open with Live Server"
          (ya neeche-right corner mein "Go Live" button dabayein)

  STEP 5: Browser khud khul jayega: http://127.0.0.1:5500/index.html
          Ab aap code mein change karein -> save (Ctrl+S) -> page khud refresh
          ho jayega. Yahi "live preview" hai.

  Band karne ke liye: neeche "Port: 5500" par click -> Stop.


--------------------------------------------------------------------------------
TARIKA 3 — PYTHON SE LOCAL SERVER (agar Python installed hai)
--------------------------------------------------------------------------------
  Windows:
    1. Folder ke andar khali jagah par Shift + Right Click
    2. "Open PowerShell window here" / "Open Terminal here" chunein
    3. Ye command chalayein:

         python -m http.server 8000

    4. Browser mein kholein:  http://localhost:8000

  Mac / Linux:
    Terminal kholein -> folder mein jayein -> phir:

         python3 -m http.server 8000

  Rokne ke liye: terminal mein Ctrl + C

  Is folder mein "start-website.bat" (Windows) aur "start-website.sh"
  (Mac/Linux) bhi diye hain — un par double click karne se server khud
  chal jayega.


--------------------------------------------------------------------------------
TARIKA 4 — VISUAL STUDIO (professional IDE)
--------------------------------------------------------------------------------
  Visual Studio (.NET wala) static HTML website ke liye bana nahi hai, lekin
  isme bhi khol sakte hain:

    1. Visual Studio kholein -> "Open a project or solution"
    2. "RPTC-Website" folder ke andar jayein -> "index.html" select karein
       (ya File -> Open -> File -> index.html)
    3. File khulne ke baad "Design/Split/Source" view milega
    4. Dekhne ke liye: Solution Explorer mein index.html par right click ->
       "View in Browser" (ya Ctrl+Shift+W)
       Tip: agar option na mile to Visual Studio mein "Open Folder" use karein.

  Behtar option: Visual Studio Code (Tarika 2) — HTML/CSS/JS ke liye yahi
  best hai aur free bhi.

================================================================================
  KOI PROBLEM AAYE TO
================================================================================

  * Page bina design ka dikhe (sirf text)
      -> style.css usi folder mein hona chahiye jahan index.html hai.
         Folder ke andar ke saare files ek saath rakhein.

  * Buttons kaam na karein / kuch na ho
      -> script.js missing ho sakta hai. Check karein ki folder mein hai.
      -> Browser mein F12 dabayein -> "Console" tab -> red error dekhें.

  * "Live Server" nahi mil raha
      -> Ctrl+Shift+X -> Extensions -> "Live Server" search -> Install
      -> Phir VS Code restart karein.

  * Purana data hata kar fresh shuru karna hai
      -> Admin page -> Settings -> "Reset demo data"
      -> Ya browser mein F12 -> Application -> Local Storage -> clear

  * Chrome mein purana version dikh raha hai
      -> Ctrl + Shift + R (hard refresh)
