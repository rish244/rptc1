# Project Report — RPTC Transport Management System

Final report for the project **RPTC Transport Management System & Online Truck Booking Website**
(front-end project of RP Transport Company, Kalamboli, Navi Mumbai).

## Files

| File | Purpose |
|---|---|
| `RPTC_Project_Report.pdf` | **The final report** (58 pages, A4, all text black). Cover, certificate, declaration, acknowledgement, contents, list of figures/tables, 8 chapters and bibliography. |
| `report.html` | Source of the report (edit here, then re-print to PDF). |
| `images/` | Screen captures of the website used in Chapter 5.5, plus the University of Mumbai and S.I.C.E.S. emblems used on the cover/certificate. |
| `fonts/` | Embedded report typeface (Tinos — metric-compatible with Times New Roman) so the PDF renders identically everywhere. |

## Structure of the report

1. Abstract
2. Introduction (system development, about the project, modules)
3. System Analysis (preliminary investigation, feasibility, data gathering, present/proposed system)
4. System Requirements (technology used, hardware & software configuration)
5. System Design (system flow diagram, 0/1/2-level DFDs, database design + data dictionary, screens)
6. System Testing (test plan, levels of testing, alpha/beta testing, 30 executed test cases)
7. Implementation and Evaluation (what is real vs. demonstration, production upgrade path)
8. Conclusion and Future Enhancement
9. Bibliography / References
